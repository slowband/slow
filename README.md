# Portfolio Dashboard MVP

React + TypeScript + Vite 기반 개인 투자 대시보드입니다.

## Run

```bash
npm.cmd install
npm.cmd run dev
```

## Build

```bash
npm.cmd run build
```

## Git

현재 저장소는 `codex/portfolio-dashboard-mvp` 브랜치로 초기 커밋까지 완료되어 있습니다.
GitHub 원격 URL만 있으면 바로 연결할 수 있습니다.

## Deploy

Vercel로 연결하면 모바일에서도 외부 접속이 쉽습니다. `vercel.json`은 SPA 라우팅용입니다.
